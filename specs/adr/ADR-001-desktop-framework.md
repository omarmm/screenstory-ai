# ADR-001 — Desktop Framework

**Status:** Proposed for technical sign-off

## Decision
Use Tauri v2, React, TypeScript, and Rust.

## Rationale
Native Linux integration, flexible desktop UI, Rust system integration, and a relatively lightweight desktop runtime.

## Consequences
Rust expertise is required. WebView compatibility and native capture integration must be tested. This decision does not authorize implementation before detailed specifications are approved.
