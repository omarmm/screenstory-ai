# SPEC-008 — Tutorial Step Editing

**Status:** Draft

## Scope
Create and edit tutorial steps generated by AI or manually by the user.

## Requirements
- Edit title and description.
- Adjust start/end timestamps.
- Add, delete, and reorder steps.
- Prevent invalid or out-of-range timing.
- Preserve source evidence references where available.

## Acceptance criteria
- Edits persist.
- Invalid timing is blocked.
- Manual changes are not overwritten by re-analysis without explicit user action.
