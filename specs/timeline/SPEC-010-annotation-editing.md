# SPEC-010 — Text Annotation Editing

**Status:** Draft

## Scope
Create and edit titles and explanatory captions.

## Requirements
- Text content, language, start/end time, position, and basic style.
- Arabic and English support.
- RTL/LTR handling.
- Font availability and shaping behavior must be verified before implementation.

## Acceptance criteria
- Arabic and English annotations render correctly in preview and export.
- Invalid time ranges are rejected.
